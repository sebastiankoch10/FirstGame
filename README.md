# FirstGame

Pixel-Art-Action-RPG im Run-Format (GameMaker 2024, GML): Runs von 30 Minuten, drei Klassen, drei Welten (Verzauberter Wald, Verfluchter Sumpf, Aschenfrost-Ruinen), Zauber, Talente, Ausrüstung, anspruchsvolle Bosskämpfe.

- **Starten:** `FirstGame.yyp` in GameMaker öffnen und F5 drücken.
- **Design (verbindlich):** [docs/Design/Leitbild.md](docs/Design/Leitbild.md). Dort stehen auch die Vorrangregeln und die Liste aller Designdokumente.
- **Arbeitsregeln für KI-Agenten:** [AGENTS.md](AGENTS.md). [CLAUDE.md](CLAUDE.md) importiert sie.
- **Aktueller Stand:** [docs/HANDOFF.md](docs/HANDOFF.md). Verlauf: [docs/LOG.md](docs/LOG.md), Entscheidungen: [docs/DECISIONS.md](docs/DECISIONS.md).
- **Systemkarte (Obsidian-Vault `docs/`):** [docs/00_Index.md](docs/00_Index.md)
- **Tests:** `python tests/tools/qa.py --plan`, danach `python tests/tools/qa.py` (Stufen-Runner, siehe [docs/Systeme/Tests & QA.md](docs/Systeme/Tests%20%26%20QA.md)).
