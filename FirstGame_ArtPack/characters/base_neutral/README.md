# Neutrale Basisfigur (Ablage, noch leer)

Hier liegen die Atlanten der schlanken, eng anliegenden Grundkleidung für Schwertkämpfer, Arkanistin und Waldläufer, sobald sie geliefert sind:
- je Klasse 4 Atlanten (walk, combat, mobility, reaction);
- je Atlas 8 × 8 Zellen, also 256 Posen je Klasse.

- Anforderungen (Maße, Posen, Dateinamen, Abnahme): `docs/Design/Assets & Pipeline.md`, Abschnitt 7.1.
- Prüfung einer Lieferung: `python tests/tools/characters/check_base_neutral.py`.
- Herkunft (Werkzeug bzw. Künstler, Datum, Lizenz) bei der Lieferung hier ergänzen.
